01 Εκκίνηση τοπικού server

Ανοίγουμε Apache & MySQL στο XAMPP

Πριν γράψουμε γραμμή κώδικα, χρειαζόμαστε δύο πράγματα να τρέχουν στον υπολογιστή μας: έναν web server που θα εκτελεί την PHP, και μια βάση δεδομένων που θα αποθηκεύει τα δεδομένα μας.

Το XAMPP μάς δίνει και τα δύο σε μία εφαρμογή. Από το XAMPP Control Panel, πατάμε Start πρώτα στο Apache και μετά στο MySQL.

Σημείο προσοχής: Όταν τα modules τρέχουν σωστά, εμφανίζονται με πράσινο χρώμα και έναν αριθμό PID. Αν δείτε κόκκινο μήνυμα, συνήθως κάποια άλλη εφαρμογή (π.χ. Skype) χρησιμοποιεί την ίδια πόρτα.

02 Πρόσβαση στη βάση

Ανοίγουμε το phpMyAdmin από τον browser

Το phpMyAdmin είναι το γραφικό περιβάλλον για τη διαχείριση της MySQL — η αντίστοιχη "dashboard" όπως είδαμε για τον Apache.

Αρκεί να ανοίξουμε τον περιηγητή μας και να πληκτρολογήσουμε την διεύθυνση:

http://localhost/phpmyadmin

Localhost σημαίνει "αυτός εδώ ο υπολογιστής". Όταν τα πάντα τρέχουν τοπικά, ο server, η βάση και ο browser βρίσκονται όλα στο ίδιο μηχάνημα.

03 Δημιουργία βάσης

Φτιάχνουμε τη βάση my_shop

Μέσα στο phpMyAdmin, πατάμε New από το αριστερό μενού. Στο πεδίο Database name γράφουμε my_shop.

Στο διπλανό μενού επιλέγουμε utf8mb4_general_ci ως collation — αυτό εξασφαλίζει ότι η βάση μας αποθηκεύει σωστά ελληνικούς χαρακτήρες και emoji.

Collation καθορίζει τον τρόπο που η MySQL συγκρίνει και ταξινομεί τα κείμενα. Με utf8mb4 καλύπτουμε όλο το φάσμα Unicode — δηλαδή Ελληνικά, Κινέζικα, emoji, τα πάντα.

04 Τα κλειδιά της σύνδεσης

Τέσσερα στοιχεία, σαν αριθμός τηλεφώνου

Όπως ακριβώς χρειαζόμαστε έναν αριθμό για να καλέσουμε κάποιον, έτσι και η PHP χρειάζεται συγκεκριμένες πληροφορίες για να εντοπίσει και να συνδεθεί με τη βάση δεδομένων.

Τα αποθηκεύουμε σε τέσσερις απλές μεταβλητές, που τις θα χρησιμοποιήσουμε αμέσως μετά.

Στο XAMPP, το προεπιλεγμένο username είναι root και το password είναι κενό. Σε πραγματικό server, αυτά είναι πάντα διαφορετικά και κρυμμένα.

05 Χτίσιμο της γέφυρας

Η συνάρτηση mysqli_connect()

Με τα κλειδιά έτοιμα, καλούμε την ενσωματωμένη συνάρτηση mysqli_connect() για να χτίσουμε την γέφυρα μεταξύ PHP και MySQL.

Το i στο mysqli σημαίνει improved — είναι η σύγχρονη επέκταση της PHP για τη MySQL.

Αν η σύνδεση πετύχει, επιστρέφεται ένα αντικείμενο σύνδεσης που το αποθηκεύουμε στη μεταβλητή $conn. Αυτή θα είναι από εδώ και πέρα το πιο σημαντικό μας εργαλείο.

● index.php
<?php $host = "localhost"; $username = "root"; $password = ""; $database = "my_shop"; // Δημιουργία της σύνδεσης $conn = mysqli_connect($host, $username, $password, $database); ?>
06 Έλεγχος σφαλμάτων

Δύο πιθανές διαδρομές — επιτυχία ή αποτυχία

Αν η σύνδεση αποτύχει (ξεχάσαμε να ανοίξουμε τη MySQL, λάθος όνομα βάσης, λάθος password), η $conn θα πάρει την τιμή false. Δεν έχει νόημα να συνεχιστεί ο κώδικας.

Η die() σταματάει ακαριαία την εκτέλεση και η mysqli_connect_error() μας δίνει το ακριβές μήνυμα λάθους.

Καλή συνήθεια: Πάντα να ελέγχουμε αν μια σύνδεση πέτυχε πριν προσπαθήσουμε να κάνουμε οτιδήποτε με τη βάση.

07 Καλή πρακτική — DRY

Ένα κεντρικό αρχείο: db_connect.php

Φανταστείτε ένα e-shop με 20 σελίδες. Θα κάνουμε copy-paste τον κώδικα σύνδεσης 20 φορές; Όχι. Αν αλλάξει το password, θα έπρεπε να ανοίξουμε και τα 20 αρχεία.

Ο κανόνας DRY (Don't Repeat Yourself) μας λέει: γράψτο μία φορά. Δημιουργούμε ένα db_connect.php με όλο τον κώδικα σύνδεσης και το καλούμε από παντού με require_once.

Το require_once εγγυάται ότι το αρχείο είναι απολύτως απαραίτητο και ότι θα φορτωθεί μόνο μία φορά ανά εκτέλεση.
● db_connect.php
<?php $host = "localhost"; $username = "root"; $password = ""; $database = "my_shop"; $conn = mysqli_connect($host, $username, $password, $database); if (!$conn) { die("Αποτυχία σύνδεσης: " . mysqli_connect_error()); } ?>
● index.php
<?php require_once 'db_connect.php'; // Από εδώ και πέρα η $conn είναι έτοιμη! ?>
08 Αποστολή ερωτήματος

Στέλνουμε SQL με mysqli_query()

Η PHP δεν ξέρει από μόνη της πώς να ψάξει στους πίνακες. Αυτό που κάνει είναι να μεταφέρει το μήνυμά μας (το SQL ερώτημα) στον διακομιστή της MySQL και να περιμένει την απάντηση.

Η mysqli_query() δέχεται δύο ορίσματα: τη σύνδεση $conn και το κείμενο του ερωτήματος. Η απάντηση επιστρέφεται ως ένα ειδικό result set — δεν είναι πίνακας ακόμα, αλλά τα δεδομένα μας σε συμπιεσμένη μορφή.

Η μεταβλητή $result είναι σαν ένα σφραγισμένο φάκελο με τις απαντήσεις της βάσης — θα τον αποκωδικοποιήσουμε στα επόμενα βήματα.

09 Έλεγχος αποτελεσμάτων

Πόσες γραμμές μας γύρισε η βάση;

Πριν προσπαθήσουμε να διαβάσουμε τα δεδομένα από το $result, ελέγχουμε αν η βάση βρήκε καθόλου εγγραφές. Αν ο πίνακας είναι άδειος, το να προσπαθήσουμε να τον διαβάσουμε μπορεί να δημιουργήσει σφάλματα ή κενή σελίδα.

Η mysqli_num_rows() μετράει πόσες γραμμές επέστρεψε η βάση. Αν είναι μεγαλύτερες του μηδέν, προχωράμε. Αλλιώς δείχνουμε ένα ευγενικό μήνυμα.

10 Η μεγάλη μεταμόρφωση

Από γραμμή SQL σε associative array

Το $result είναι συμπιεσμένο. Η mysqli_fetch_assoc() κόβει μία γραμμή τη φορά, τη μετατρέπει σε γνώριμο πίνακα PHP, και προχωράει στην επόμενη.

Επειδή φέρνει μόνο μία γραμμή κάθε φορά, τη βάζουμε μέσα σε ένα while: "συνέχισε να φέρνεις γραμμές μέχρι να τελειώσουν". Όταν τελειώσουν, η συνάρτηση επιστρέφει false και ο βρόχος σταματάει.

fetch = "πήγαινε και φέρε" · assoc = associative array. Δείτε δίπλα την κίνηση: η γραμμή του Laptop "γίνεται" ένα PHP array.
